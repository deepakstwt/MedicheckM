# MediCheck

MediCheck is an iOS application designed to help users manage their healthcare and fitness needs. The app provides a user-friendly interface for tracking health-related activities and medications.

## Features

- Modern SwiftUI-based user interface
- Support for both iPhone and iPad devices
- Healthcare and fitness tracking capabilities
- User notification support
- Portrait and landscape orientation support

## Requirements

- iOS 16.0 or later
- Xcode 14.0 or later
- Swift 6.0

## Installation

1. Clone the repository:
```bash
git clone [repository-url]
```

2. Open the project in Xcode:
```bash
cd MediCheck
open Package.swift
```

3. Build and run the project in Xcode

## Project Structure

- `MediCheckApp.swift`: Main application entry point
- `MainView.swift`: Primary view of the application
- `View/`: Directory containing additional view components
- `Package.swift`: Swift package manager configuration
